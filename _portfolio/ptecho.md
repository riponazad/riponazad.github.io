**PTEcho** (Point Tracking in Echocardiography) is a research pipeline and benchmark framework for evaluating point tracking algorithms in 2D echocardiographic data.

## Overview

PTEcho provides a standardized evaluation framework to benchmark various point tracking methods — from classical optical flow approaches to modern deep learning models — on echocardiographic sequences. It supports the broader research initiative in myocardial motion estimation at NTNU's ISB department.

## Key Features
- Standardized benchmark protocol for echocardiographic point tracking
- Interfaces for multiple tracking algorithms (classical and deep learning)
- Evaluation metrics for tracking accuracy and clinical relevance
- Integration with strain estimation pipelines

## Technologies
- Python
- PyTorch
- Medical imaging analysis tools
